# Changelog: Tessera v0.3.0 (1.21 – 26.3)

**Tessera** now works on every Minecraft version from 1.21 to 26.3, not just 1.21.1. This update also fixes fire, lanterns and other animated textures with see-through parts, which looked noticeably worse than the rest of the game.

---

## Key Features & Changes

* **Many More Minecraft Versions**: Works on Minecraft 1.21 – 1.21.11 and 26.1 – 26.3, with NeoForge. Pick the Tessera file for your Minecraft version (the Modrinth and CurseForge apps do this for you). Every one of these versions passed an automatic test in the game, animated textures included.
* **Sharper Animated Textures**: Fire, lanterns, campfires, sculk and other animated textures with see-through parts now look as sharp as everything else.
* **See Your Savings with F3**: Press F3 to see how much video memory Tessera saves. On 1.21 – 1.21.4, hold F3 and press 4 for a detailed list. On 1.21.10 and newer, turn the detailed list on in the game's debug options; Tessera's own "Show Extended Atlas Breakdown" setting only works on 1.21 – 1.21.4. On 1.21.5 – 1.21.9, Tessera doesn't show up on the F3 screen, but it still saves just as much video memory.
* **Join Any Server**: Tessera no longer stops you from joining servers that don't have Celeris. Before, the server turned you away.
* **Requirements**: Now needs **Celeris** 0.2.1 or newer. Windows and Linux only: macOS doesn't support the texture format Tessera needs.
